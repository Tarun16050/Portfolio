# Tarun Patidar — Portfolio

Personal portfolio site for **Tarun Patidar**, PHP & Laravel Backend Engineer. A single-page, dark-themed site built with vanilla HTML, CSS, and JavaScript — no framework, no build step.

🔗 Live sections: About · Skills · Experience · Projects · Education · Contact

## Tech Stack

- **HTML5** — semantic single-page markup (`index.html`)
- **CSS3** — custom design system with CSS variables, glassmorphism panels, responsive layout (`style.css`)
- **JavaScript (vanilla)** — scroll reveal animations, typing effect, skill bar animation, particle background, custom cursor, mobile nav (`script.js`)
- **Google Fonts** — Space Grotesk, Inter, JetBrains Mono

## Features

- Animated hero section with typing effect and live code-console visual
- Scroll-triggered reveal animations (fade-up / slide / zoom)
- Animated stat counters and skill progress bars
- Responsive project grid with hover tilt effect
- Timeline-style experience log
- Education cards with CGPA highlights
- Downloadable resume (PDF)
- Fully responsive, mobile-friendly navigation

## Getting Started

No build tools or dependencies are required. Just open the site locally:

```bash
git clone https://github.com/Tarun16050/<repo-name>.git
cd <repo-name>
```

Then either:
- Open `index.html` directly in a browser, or
- Serve it locally for the best experience (recommended, since some browsers restrict local file access):

```bash
npx serve .
# or
python -m http.server 5500
```

Visit `http://localhost:5500` (or the port shown).

## Customization

- **Colors & theme tokens** — edit CSS variables at the top of `style.css` (`--bg`, `--blue`, `--purple`, `--cyan`, etc.)
- **Content** — update text, skills, projects, and experience directly in `index.html`
- **Resume** — replace `Tarun_Patidar_Resume.pdf` with an updated file of the same name
